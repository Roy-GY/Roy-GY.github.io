# Design: Jon Barron-Style Academic Homepage

**Date:** 2026-05-18
**Status:** Draft

## Goal

Replace the current Hexo blog with a pure HTML/CSS academic personal homepage styled after Jon Barron's website (jonbarron.info).

## Approach

Pure HTML/CSS static site (no static site generator). Adapt Jon Barron's open-source template by replacing all personal content while keeping the visual design and layout structure.

## File Structure (After Migration)

```
├── index.html          # Single-page academic homepage
├── stylesheet.css      # Styling (Lato font, responsive, blue/orange accent)
├── images/
│   └── me.png          # Profile photo (copied from source/images/me.png)
├── data/               # CV PDF, BibTeX files, bio text
├── .gitignore          # Updated for new file structure
├── .deploy_git/        # Preserved: Git deployer state
└── CNAME               # Optional custom domain
```

## Files to Remove

- `_config.yml`, `_config.landscape.yml`
- `node_modules/`, `package.json`, `package-lock.json`
- `scaffolds/`, `source/`, `themes/`
- `db.json`
- `public/` (regenerated by deploy)
- `CLAUDE.md` (will regenerate for new structure)

## Visual Design

- **Font:** Lato (Google Fonts, via @font-face in stylesheet.css)
- **Link color:** #1772d0 (blue), hover: #f09228 (orange)
- **Layout:** max-width 800px, centered, table-based (same as Jon Barron template)
- **Responsive:** media queries in stylesheet.css for mobile
- **Highlight:** #ffffd0 yellow background for key items

## What Stays from Jon Barron Template

- `stylesheet.css` — keep as-is, minor modifications for new sections
- Layout HTML structure (tables, max-width, centered)
- Meta tags structure (update author, title, description)

## What Changes
